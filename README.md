## 📖 About

**Kodex Repository** is a curated collection of high-quality extensions for
[Cloudstream 3](https://github.com/recloudstream/cloudstream), the open-source
Android streaming app.

Every extension here is engineered for a smooth, dependable experience:

- **Reliable** — automatic domain recovery keeps streams working even when a
  source rotates its domain or front-end.
- **Ad-free** — links resolve straight to the source media, bypassing ads,
  shorteners and captchas wherever possible.
- **Fast** — direct, full-quality streams with HTTP Range support; no
  transcoding or re-encoding.
- **Always fresh** — the `repository.json` manifest points at an auto-generated
  `plugins.json`, so updates reach Cloudstream without any manual steps.

## ✨ Features

- **One-click install** — add the repository URL and every extension is ready instantly.
- **Automatic domain recovery** — extensions detect and switch to the current working domain on their own.
- **Direct streaming** — full-quality streams with Range support, no re-encoding.
- **Auto updates** — extensions are compiled and published automatically by CI.
- **Clean & lightweight** — no bloat, minimal dependencies, fast cold starts.

## 🚀 Installation

1. Open **Cloudstream 3**.
2. Go to **Settings → General → Provider repos → Add repository**.
3. Paste the URL below and confirm:

```
https://raw.githubusercontent.com/sabbirexist/Kodex-Repository/main/repository.json
```

That's it — the extensions will appear under **Extensions**.
